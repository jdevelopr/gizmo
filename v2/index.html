Buy land to grow the plot — and with the first ring comes a second feed, so two lines have to meet at an Assembler before anything really pays. Every round the order board asks the only question that matters: is your factory shipping more than it ever has? Two to four players, each on a phone.

This device becomes the floor: it runs every factory and shows them all. It is not a player — everyone joins on a phone.

Practice opens the same Setup panel, so you can try a plot size before putting it in front of anyone.
